## 🔍 defuddle

### 功能
- 从网页中提取干净的文章内容
- 去除广告、侧边栏等杂乱元素
- 返回 Markdown 正文 + 元数据

### 使用场景
- 提取新闻文章正文
- 保存网页内容为 Markdown
- 内容归档整理

### 使用示例
```
用户: 提取这篇文章的内容 https://example.com/article
AI: 使用 defuddle 提取正文

输出:
- 标题: xxx
- 作者: xxx
- 发布日期: xxx
- 正文: (Markdown格式)
```

### 技术
- 基于 Obsidian CEO 的 CLI 工具
- 封装成 OpenClaw Skill

## 🌐 bb-browser

### 功能
- 通过浏览器 + 用户登录态获取信息
- 访问公域和私域内容
- 可访问登录后页面、内部系统
- 执行表单填写、页面操作

### 使用场景
- 访问需要登录的网站
- 抓取社交媒体内容
- 内部系统数据提取
- 自动化网页操作

### 安全策略 ⚠️

#### 可直接操作
- ✅ 普通新闻、博客网站
- ✅ 社交媒体 (Twitter/X、小红书、知乎)
- ✅ 内部文档系统
- ✅ 电商网站 (只读浏览)
- ✅ 技术文档、GitHub

#### 必须用户确认
- ⚠️ 银行、金融机构
- ⚠️ 支付、钱包类网站
- ⚠️ 涉及资金操作的页面

#### 禁止访问
- ❌ 政府敏感系统

### 使用示例
```
用户: 帮我查看这条推文的内容 https://x.com/...
AI: 使用 bb-browser 访问 (✅ 直接执行)

---

用户: 帮我查看银行账户余额
AI: 涉及银行网站，需要确认：
   "即将访问银行网站，是否继续？"
用户: 是的
AI: 使用 bb-browser 访问 (⚠️ 确认后执行)
```

### 配置
无需额外配置，使用系统浏览器
